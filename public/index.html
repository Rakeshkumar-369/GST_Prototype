How this prototype works

  1. Vendors – register a vendor with GSTIN. The portal validates the check digit offline, then calls the mediator's GSTIN search API and stores the GSTN legal name, state and status. Click Load sample vendors for a quick start.
  2. Payments – the vendor pays corpus fund, documentation, process and transaction fee. Only the transaction fee attracts 18% GST. A Rule 46 compliant tax invoice is issued instantly (like Uber / Zomato) — B2B if the GSTIN is active, B2C otherwise.
  3. Bulk simulate – generate thousands (up to 2 lakh) of payments for a month to test the 1.5 lakh / month volume.
  4. GSTR-1 Filing – build the monthly batch (b2b, b2cs, hsn, doc_issue), connect to GSTN via OTP, upload in parts, review the GSTN summary and file with EVC → ARN.
  5. Vendor ITC – see the vendor-side GSTR-2B: every invoice now appears as eligible ITC.
